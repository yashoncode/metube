## Validation and limitations

- Unit tests on the release tree: **633 in `smarttubetv` and 238 in `common`
  passed** (1 opt-in benchmark skipped; 21 fewer than 1.10.0, the park tests
  left with the feature); focused `youtubeapi` suites (309, incl. bot wall,
  visit order, WEB_EMBED skip, preconnect, stale-connection guard) pass. The
  full `youtubeapi` suite keeps its pre-existing live-account/network failures.
- Every change in round 3, the UX branch and the follow-ups got a Codex
  (gpt-6-sol, astra for the visitor decision) adversarial review; findings were
  fixed or answered (HANDOFF §31).
- Pixel 9 (Android 17), owner's signed-in account, Wi-Fi and Movistar LTE,
  release builds (numbers in STATUS): launch, Home, related hops, cold share
  links, resumes, autoplay, 95 s idle on LTE, carrier verdict learn/restore/
  clear, offline wait, Opus
  pre-roll A/B, HTTP/2 on every InnerTube answer, the integrated UX build
  (rating/snackbar flows, night-mode switch, dubbed-audio sheet, reopen, no
  ANR), the WEB_EMBED skip (age-restricted video through TV_TIZEN, no
  WEB_EMBED request) and the re-download fix.
- Signed release assembly passed. APK package/version and signing certificate
  checked with `aapt` and `apksigner`; the release is not debuggable.
- Pixel 9: in-place upgrade to the exact signed ARM64 artifact, app and account
  data retained; the install lands `[status=speed-profile] [reason=install]`
  from the embedded profile (1.10.1 over the 1.10.0 debug build left by the
  investigation: `versionCode=11001`, not debuggable, speed-profile at install).
- Full `lintStmobileRelease` was not re-run beyond the release assembly's lint
  vital check.
- Known gaps: the first stall per carrier still costs ~7-8 s once; a duplicate download can be queued while the first runs; a download whose
  cache-dir parts the system deletes can stay at "Finishing…"; a rating YouTube
  rejects with an HTTP error still counts as saved; YouTube can still refuse
  some videos and accounts; SABR stays off.

## Distribution

Same tester-group workflow as 1.9.0: signed **ARM64 release APK** plus the
Gila announcement and poster, sent only to the NewTube tester chat at the
owner's explicit request. No chat identifiers or participant details are kept
in this repository.

changelogs and artwork are versioned on `main`. Same package and signing
certificate as 1.9.0, so it upgrades in place. Do not uninstall or clear data.

off, card-menu reorder for untouched menus, buffer alignment) run on first
launch.
