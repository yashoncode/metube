# NewTube 1.10.1 release artwork

Final asset: `images/release_1.10.1.png` (1080×1350, portrait 4:5).

Mode: no image-generation tool was available in the release session
(2026-09-26; re-rendered for 1.10.1 on 2026-09-27), so the poster is a typographic composition rendered from a
hand-written HTML/CSS/SVG page and screenshotted with Chrome (`agent-chrome`,
`page.set_content`). There is no caricature: the subject is an old rotary
telephone with its handset lifted, its cord running to a modern phone that is
starting a video (play button, a short red progress bar, speed marks), on the
same navy stage / cream and gold lettering palette as the 1.8.0 and 1.9.0
posters.

Text, exactly and only: "NewTube 1.10.1", "EDICIÓN GILA", "¿Es el enemigo?",
"Que se ponga… rápido.", footer "PARODIA · HOMENAJE NO OFICIAL". No numbers,
no claims, no logos, no watermark.

It is fictional artwork and an unofficial homage to Miguel Gila, not an
endorsement or a quotation of a real routine beyond the well-known
"¿Es el enemigo? Que se ponga" line it plays on.
